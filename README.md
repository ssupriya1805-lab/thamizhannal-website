# தமிழண்ணல் இணையதளம் (React + Tailwind)

## இயக்குவது எப்படி

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # dist/ கோப்புறையில் production build
```

இந்த project இப்போது **Tailwind CSS**-ஐயும் (புதிய sections-க்கு) மற்றும்
உங்கள் அசல் `style.css`-ஐயும் (முழுத் தளத்தின் அடிப்படை theme-க்கு)
சேர்த்துப் பயன்படுத்துகிறது. இரண்டும் ஒன்றுக்கொன்று முரண்படாமல்
`src/index.css`-ல் இணைக்கப்பட்டுள்ளன.

## இந்தச் சுற்றில் என்னென்ன மாற்றப்பட்டது

1. **முகப்பு பக்கம் — ஒலி & காணொளி** — "கேளுங்கள், பாருங்கள்" எனும்
   புதிய section சேர்க்கப்பட்டுள்ளது (audio player + YouTube embed).
   `src/data/media.js`-ல் உங்கள் mp3 பாதை மற்றும் YouTube video ID-ஐக்
   கொடுக்கவும் — இல்லாதவரை "இன்னும் சேர்க்கப்படவில்லை" எனக் காட்டும்.

2. **நூல்கள் பக்கம் — வகைப் பிரிவுகள்** — thamizhannal.org தளத்தில்
   உள்ளதைப் போலவே 11 பிரிவுகள் (இலக்கியம், தொல்காப்பியம், திருக்குறள்,
   இலக்கணம், உரை, மொழியியல், ஆய்வு, தமிழண்ணல், தமிழர், புதினம்,
   மற்றவை) subheading-ஆகவும், மேலே quick-jump chip-களாகவும்
   காட்டப்படுகின்றன. நூல் இல்லாத பிரிவில் "விரைவில் சேர்க்கப்படும்"
   எனத் தெரியும். `src/data/books.js`-ல் ஒரு object சேர்த்தால் போதும்.

3. **நூல் திறக்கும் பக்கம் — முழுவதுமாக மறுவடிவமைப்பு** — முன்பு
   இருந்த வெள்ளை/பொருந்தாத தோற்றமும், தெரியாத breadcrumb-உம் சரி
   செய்யப்பட்டு, தளத்தின் இருண்ட தலைப்புப் பட்டை (dark page-banner)
   பாணியிலேயே இப்போது காட்டப்படுகிறது. PDF-ஐ காட்ட, "flipbook"
   canvas விதத்திற்குப் பதிலாக **நேர்த்தியான, நம்பகமான PDF viewer
   card** (browser-இன் native PDF காட்சி) பயன்படுத்தப்படுகிறது —
   "புதிய சாளரத்தில்" மற்றும் "பதிவிறக்கம்" பொத்தான்களுடன்.

4. **கட்டுரைகள் — real reading page** — "தொடர்ந்து படிக்க" இப்போது
   `/articles/<slug>` பக்கத்தைத் திறக்கும், முழு கட்டுரை உள்ளடக்கத்
   துடன் (`src/data/articles.js`).

5. **வாழ்க்கைப் பயணம் (Gallery) — 9 subheading-கள்** — ஆரம்பகால
   வாழ்வு, கல்லூரி வாழ்வு, ஜப்பான் பயணம், மணி விழா, அமெரிக்கா பயணம்,
   தமிழ்வழிக் கல்வி, சான்றோர் பேரவை, நூல் வெளியீடுகள், உயர் விருதுகள்
   — ஒவ்வொன்றிலும் 3-4 காலி image slot-கள். படம் இல்லாதவரை "படம்
   இன்னும் இல்லை" எனக் காட்டி, தளம் உடையாமல் இருக்கும்.

6. **விருதுகள் பக்கம் (தனி பக்கம், /awards)** — இப்போது 2
   subheading-கள் மட்டும்: "விருதுகள்" மற்றும் "உலக தமிழ் விருது",
   ஒவ்வொன்றிலும் 5 image slot-கள்.

7. **புதிய பக்கம் — நினைவேந்தல் (/remembrance)** — Header-ல் புதிய
   nav item சேர்க்கப்பட்டுள்ளது.

## படங்கள் / PDF சேர்க்க எங்கே போடுவது

```
public/
  books/                        ← நூல் PDF கோப்புகள்
  media/                        ← audio mp3 கோப்பு
  images/
    books/                      ← நூல் அட்டைப் படங்கள்
    gallery/
      gallery-general/          ← வாழ்க்கைப் பயண படங்கள்
      awards/                   ← விருது படங்கள்
```

ஒவ்வொரு கோப்புறையிலும் ஒரு README.md உள்ளது — என்ன பெயரில் கோப்பு
போட வேண்டும் என்பதை விளக்குகிறது.

## தரவு கோப்புகள் (எடிட் பண்ண இவை மட்டும் போதும்)

- `src/data/books.js` — நூல் பட்டியல் + வகைகள்
- `src/data/gallery.js` — வாழ்க்கைப் பயணப் படப் பிரிவுகள்
- `src/data/awards.js` — விருதுப் படப் பிரிவுகள்
- `src/data/articles.js` — கட்டுரைகள் (தலைப்பு + முழு உள்ளடக்கம்)
- `src/data/media.js` — முகப்புப் பக்க ஒலி/காணொளி
