# நூல் PDF-கள் இங்கே போடவும்

இந்த கோப்புறையில் ஒவ்வொரு நூலின் PDF கோப்பையும் போடவும்.
கோப்புப் பெயர் src/data/books.js-இல் உள்ள pdfUrl-உடன் பொருந்த வேண்டும்.

எடுத்துக்காட்டு:
  book1.pdf
  book2.pdf
  book3.pdf
  ...

PDF இல்லாத நூலுக்கு எதுவும் போட வேண்டாம் — "PDF இன்னும் சேர்க்கப்படவில்லை"
என்று தானாகக் காட்டப்படும்.

குறிப்பு: பதிப்புரிமை (copyright) உள்ள நூல்களை உங்களுக்கு அதற்கான
உரிமை / அனுமதி இருந்தால் மட்டுமே பதிவேற்றவும்.
