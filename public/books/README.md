# நூல் PDF-கள் இங்கே போடவும்

இந்த கோப்புறையில் ஒவ்வொரு நூலின் PDF கோப்பையும் போடவும்.
**கோப்புப் பெயர் நூலின் தலைப்புடன் EXACT-ஆக ஒரே மாதிரி இருக்க வேண்டும்**
(src/data/books.js-ல் உள்ள title அப்படியே), இறுதியில் ".pdf".

எடுத்துக்காட்டு:
  பரிசில் வாழ்க்கை.pdf
  சங்க இலக்கிய ஒப்பீடு.pdf
  தொல்காப்பியர்.pdf
  ...

- PDF இல்லாத நூலுக்கு எதுவும் போட வேண்டாம் — "PDF இன்னும்
  சேர்க்கப்படவில்லை" என்று தானாகக் காட்டப்படும்.
- அட்டைப் படம் தனியாகத் தேவையில்லை — PDF-இன் முதல் பக்கமே தானாக
  அட்டைப் படமாகக் காட்டப்படும்.
- நூல் திறக்கும் பக்கத்தில் "flipbook" (பக்கம் புரட்டும் காட்சி)
  இந்த local PDF-லிருந்தே உருவாக்கப்படும்.

குறிப்பு: பதிப்புரிமை (copyright) உள்ள நூல்களை உங்களுக்கு அதற்கான
உரிமை / அனுமதி இருந்தால் மட்டுமே பதிவேற்றவும்.
